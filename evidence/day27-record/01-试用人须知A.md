# 试用人须知（请照着做，不要看后面的答案）

> 你要帮我试一个还没做完的网页。**过程中不要问我怎么做**，
> 你就按自己的理解去点，遇到任何"我不知道该干嘛""怎么没反应""这是什么东西"的地方，
> 都当场记下来 —— 那些正是我要的东西，比你夸我做得好有用得多。

## 一、你要打开的东西

在你自己的电脑（或手机）上打开这个地址：

```
http://localhost:4173/catalog.html
```

打开以后请**先不要动鼠标**，看一眼屏幕，然后回答第 1 题。

## 二、请你做的事（按顺序，但中间卡住就停下记录）

| # | 请你做的事 | 做完先记录 |
|---|---|---|
| 1 | 打开页面，什么都不点，看 5 秒 | 你看到的第一眼，用一句话描述 |
| 2 | 用你自己的话回答：**这个页面是干什么的？** | 把答案写下来（写"不知道"也算答案） |
| 3 | 在页面上随便找找，找出有信息的地方读一读 | 你读了什么？看懂了什么？ |
| 4 | 页面上试着输入你想找的东西（想到什么输什么） | 你输了什么？出现什么？符合你的预期吗？ |
| 5 | 把你输入的东西删掉 | 页面有没有回到你一开始看到的样子？ |
| 6 | 试着用键盘（不用鼠标）操作这个页面 | 能不能做到？卡在哪？ |
| 7 | 全部玩完之后，回答：**愿不愿意再看一次？为什么？** | 一句话就行 |

## 三、记录格式（每条按这个写，越具体越好）

```
第 X 步：
- 我做了什么：
- 我以为会出现什么：
- 实际出现了什么：
- 我当时的想法/情绪（困惑？无聊？想关掉？）：

真正让我浪费时间的地方是：
```

## 四、特别请你留意

1. **第一个让你停下来的地方是什么** —— 停在那是不知道点什么，还是不知道点完会怎样？
2. 页面顶端那行小字**「数据来源：……」**，你第一眼看的时候**注意到它了吗**？知道它在说什么吗？
3. 有没有哪个地方，你以为可以点，点了却没反应？

## 五、做完之后

把你写的东西原样发给我（截图或文字都行），**不用润色、不用改得客气**。
另外请给我一张**你屏幕的截图**，要带上浏览器地址栏。
