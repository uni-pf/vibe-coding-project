# 试用人须知（手机版 · 请照着做）

> 你要帮我试一个还没做完的网页。**过程中不要问我怎么做**，
> 卡住、看不清、找不到的地方都当场记下来——那正是我要的东西。

## 一、打开

用你手机自带浏览器打开：

```
http://<你电脑的局域网IP>:4174/catalog.html
```

（我发你消息时会带具体 IP；必须和我在同一个 Wi-Fi 下才能打开。）

## 二、请按顺序做（卡住就停下记录）

| # | 请你做的事 | 记录 |
|---|---|---|
| 1 | 打开页面看 5 秒，什么都不点 | 第一眼印象一句话 |
| 2 | 用你自己的话说这是干什么的 | 写下来 |
| 3 | 找找有没有字太小/太挤/看不清的地方 | 哪里？ |
| 4 | 在输入框输入"灯" | 出现了什么？ |
| 5 | 点"清空" | 回到全部了吗？按钮好点吗？ |
| 6 | 只用一只手（拇指）操作 | 哪些地方够不着？ |
| 7 | 愿不愿意再看一次？为什么 | 一句话 |

## 三、记录格式

```
第 X 步：我做了什么 / 我以为会出现什么 / 实际出现了什么 / 我的想法
```
