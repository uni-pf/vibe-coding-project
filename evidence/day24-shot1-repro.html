② 定位 · 排除法（怎么锁定的）

候选原因排查动作结论
接口挂了网络清单看 /api/objects200，5 条数据正常返回 → 排除
JS 异常控制台全量收集仅 1 条资源 404，无 JS 异常 → 排除
静态资源挂了js / css 逐一核对全部 200 → 排除
缺图标声明查 HTML 与 public/index.html / catalog.html 均无 <link rel="icon">，public/ 无任何图标文件

根因：页面没有声明图标时，Chrome 会按规范行为自动请求 /favicon.ico；本项目没有这个文件，preview 服务器返回 404，控制台必现一条红色报错。该问题在 Day 21 周验收（W11）已记录并「记入下周」，正是今天要修的 Bug。
